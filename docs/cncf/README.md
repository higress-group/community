# Higress CNCF Review Materials

This directory contains the project-maintained working copies used to prepare
Higress for CNCF Incubation:

- [General Technical Review](./general-technical-review.md)
- [Governance Review](./governance-review.md)
- [Security Self-Assessment](./security-self-assessment.md)
- [Incubation Application](./incubation-application.md)

These files are project self-assessments. CNCF reviewers may amend their
findings, and formal reviews require dated snapshots in the appropriate CNCF
repository. Code and repository-specific evidence continues to link to the
relevant Higress software repository.
