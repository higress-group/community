# Higress Community

This repository is the authoritative home for project-wide Higress governance,
community operations, maintainer information, public meetings, adoption
evidence, roadmap process, and CNCF review materials.

Higress source code, releases, installation documentation, and repository-
specific contribution workflows remain in the
[primary Higress repository](https://github.com/higress-group/higress).

## Project information

| Resource | Description |
| --- | --- |
| [Governance](./GOVERNANCE.md) | Project roles, decision making, vendor neutrality, and subproject lifecycle |
| [Maintainers](./MAINTAINERS.md) | Current project-wide maintainer roster and lifecycle |
| [Community](./COMMUNITY.md) | Public and private communication channels |
| [Community meetings](./MEETINGS.md) | Public schedule, joining details, agendas, notes, and recordings |
| [Adopters](./ADOPTERS.md) | Public production adoption evidence |
| [Roadmap](./ROADMAP.md) | Project-wide roadmap and change process |
| [Code of Conduct](./CODE_OF_CONDUCT.md) | The project-adopted CNCF-aligned Code of Conduct |
| [CNCF materials](./docs/cncf/) | Incubation working copy and project review self-assessments |

## Contributing

Community governance and documentation changes are proposed through issues and
pull requests in this repository. See [CONTRIBUTING.md](./CONTRIBUTING.md).
Code, plugin, Helm, CLI, and implementation changes belong in the relevant
Higress project repository.
