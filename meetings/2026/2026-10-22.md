### 3. Feature deep dives (15 min)

#### 3.1 Built-in Endpoint Picker (6 min)

- Pipeline: Filter → Normalize → Score → Pick → Feedback. Queue depth, KV
  cache, and approximate prefix cache carry default weights 2, 2, and 3;
  gateway-local inflight uses weight 1; LoRA affinity and failure EWMA default
  to 0.
- Fail-open when no candidate is usable or a hostcall/override fails; missing
  optional signals never hard-filter an endpoint.
- GIE v1.4 integration through the Higress `endpointPickerRef` convention; the
  external EPP/ext_proc path remains available.
- Benchmark from [#4352](https://github.com/higress-group/higress/pull/4352) at
  concurrency 40, 1200 requests per group: average TTFT 311.63 → 214.42 ms
  (-31.19%), P99 TTFT 1106.76 → 933.62 ms (-15.64%), throughput 489.71 →
  565.65 token/s (+15.51%). External EPP still has a better P50 TTFT, and is
  slightly better under concurrency 20; treat this as a tail-latency and
  deployment-simplicity win, not a universal one.
- Next: adoption docs and examples, GIE conformance
  ([#4280](https://github.com/higress-group/higress/issues/4280)), and exact
  KVEvents ([#4297](https://github.com/higress-group/higress/issues/4297)).

#### 3.2 MCP Server 2.0.3 (4 min)

- `server.protocolStrategy: auto` probes the upstream profile and selects the
  modern two-call or legacy four-call protocol; a failed local probe does not
  send an upstream request.
- `inputSchema` validation failure now degrades to a generation-scoped
  validation-unavailable state instead of failing plugin startup, and
  `clientCapabilities` ignores unknown fields for MCP 2026-07-28 compatibility.
- Authentication tightened for RAG write tools and OpenAPI MCP credentials;
  SSE fragment and cross-chunk issues fixed in mcp-session and ai-proxy.
- Open items: [#5168](https://github.com/higress-group/higress/issues/5168)
  with fix PR [#5209](https://github.com/higress-group/higress/pull/5209),
  [#4879](https://github.com/higress-group/higress/issues/4879), and
  [#5011](https://github.com/higress-group/higress/issues/5011) /
  [#5012](https://github.com/higress-group/higress/issues/5012).

#### 3.3 `hgctl upgrade --from-helm` (2.5 min)

- Parses the existing Helm release, rebuilds a temporary profile, applies
  overlays in order, validates the result, and then reuses the normal render
  and apply flow.
- It does not persist a profile or rewrite Helm history, so a failed migration
  can fall back to Helm management.

#### 3.4 Post-release security hardening (2.5 min)

- The real-IP parsing panic family was fixed consistently across ip-restriction
  ([#4944](https://github.com/higress-group/higress/pull/4944)), chatgpt-proxy
  ([#4946](https://github.com/higress-group/higress/pull/4946)), geo-ip
  ([#4948](https://github.com/higress-group/higress/pull/4948)), and
  cluster-key-rate-limit
  ([#4950](https://github.com/higress-group/higress/pull/4950)).
- Duplicate top-level `model` members are now rejected at the AI plugin entry
  ([#5124](https://github.com/higress-group/higress/pull/5124)) and the check is
  rolling out to more AI plugins; xDS listener exposure was reduced
  ([#5123](https://github.com/higress-group/higress/pull/5123)); ai-token-ratelimit
  token accounting was fixed
  ([#5080](https://github.com/higress-group/higress/pull/5080)).
- Still under review: ai-token-ratelimit fail-closed behavior for unresolvable

  This changes the "allow when the header is missing" behavior and needs an

### 4. HiRoute project update (10 min)

- **What it is.** A local-first routing and collaboration engine for
  long-running agent work: it chooses a model at agent-turn / context-hold
  boundaries instead of switching on every tool call.
- **Release pace.** Four releases in 19 days, from v0.1.0 on 2026-09-22 to
  v0.3.1 on 2026-10-11: desktop and Linux CLI, built-in decision model, Qoder /
  Pi / DeepSeek Harness integrations, recovery and stability fixes.
- **Four layers.** Routing plans (fixed, smart saving, free-first, ordered
  failover), agent access and execution, a public Decision API with the
  optional Jev extension, and local evidence for every decision.
- **Engineering.** Rust workspace on a pingora-based Gateway Core; the full
  backend suite dropped from 814.9 s to 140.6 s (2164 tests passed, 19 ignored).
- **Boundaries.** MVP; Windows is not supported, and some real-model acceptance
  on macOS Intel / Linux ARM64 is still in progress.
- **Relationship to Higress.** The ExtProc path for feeding HiRoute decisions
  into Higress remains an exploration, not a production integration. This
  segment will cover the interface boundary and failure semantics under
  discussion.
