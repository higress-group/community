# Contributing to Higress Community

This repository accepts changes to project-wide governance, maintainer
information, communication channels, meetings, adoption evidence, roadmap
process, and CNCF review materials.

Use the relevant Higress code repository for implementation changes, bug
reports, feature requests, build instructions, and repository-specific
contribution guidance. The primary code contribution guide is
[`higress-group/higress/CONTRIBUTING_EN.md`](https://github.com/higress-group/higress/blob/main/CONTRIBUTING_EN.md).

## Proposing a change

1. Open an issue when a change requires community discussion or changes project
   governance, scope, roles, or goals.
2. Submit a focused pull request that links the public discussion and explains
   the rationale and expected outcome.
3. Follow the lazy-consensus and conflict-handling process in
   [`GOVERNANCE.md`](./GOVERNANCE.md).
4. Sign off commits in accordance with the Developer Certificate of Origin.

Meeting agenda topics follow the process in [`MEETINGS.md`](./MEETINGS.md).
Final meeting records use the format documented in
[`meetings/README.md`](./meetings/README.md).

All participation is subject to the
[`CODE_OF_CONDUCT.md`](./CODE_OF_CONDUCT.md).
